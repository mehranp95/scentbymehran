# خلاصه دانش — صدای ScentbyMehran

برای جزئیات کامل → `docs/style-guide.md`

## یک جمله‌ای
ریویوهای محاوره‌ای فارسی که از حالِ زندگی شروع می‌کنند، به مفهوم عطر پل می‌زنند، ۲–۵ نوت معنادار می‌گویند، یک «هنر» پیدا می‌کنند، و با موقعیت + رنگ لباس جمع می‌بندند.

## دو رجیستر
- **A (پیش‌فرض):** روایی/اسه‌ای — Vibrato، Jetty، Fiero، Jimmy Choo…
- **B:** تست زنده روی پوست با تایم‌استمپ — پست‌های اولیه کانال

## استخوان‌بندی A
عنوان لاتین → قلاب زندگی هم‌معنا → پل به عطر → زمینه برند → بو + هنر → پرفورمنس → موقعیت/استایل → بست کوتاه با «...»

## امضاهای زبانی
آچار فرانسه · استوار · طراوت · رسالت · رفرنس · پرفورمنس · اثر هنری · خلوت · تعادل / افراط و تفریط · بک گراند · دیزاین

## سلیقه غالب (از پیکره)
مرکباتی / فرش / معتدل-خنک · مردانه · دوری از گرم-ادویه‌ای سنگین · دکانت‌فرهنگ ایرانی · بی‌تفاوتی به مرز نیش/دیزاینر وقتی حس درست باشد
